# fasthtml-tailwindcss-cli

Platform-specific wheels containing the official standalone Tailwind CSS CLI binary. It is installed as the `dev` extra of [fasthtml-tailwindcss](https://pypi.org/project/fasthtml-tailwindcss/) and is not needed to serve a prebuilt stylesheet.

The package version matches the bundled Tailwind CSS release. See the [project repository](https://github.com/SpaceShaman/fasthtml-tailwindcss) for usage and release details.
